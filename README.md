# Форма реєстрації

## Опис
Цей проєкт реалізує просту форму реєстрації з перевіркою введених даних за допомогою JavaScript.

## Файли
- **form.html** — основна HTML-розмітка форми.  
- **style.css** — оформлення елементів (шрифти, кольори, відступи, ефекти при наведенні).  
- **script.js** — логіка перевірки введення:
  - поле імені не може бути порожнім;  
  - email перевіряється за допомогою регулярного виразу;  
  - пароль має містити щонайменше 6 символів;  
  - повтор пароля повинен збігатися з основним.  
- **.gitignore** — опціональний файл для ігнорування службових даних.

## Як запустити
Відкрийте файл `form.html` у браузері.
